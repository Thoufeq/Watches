# ⌚ ChronoPage

A modern and responsive **Watches Showcase** website built using **HTML, Tailwind CSS, and JavaScript**. This project focuses on clean UI design, smooth interactions, and structured product presentation, making it suitable for showcasing premium watches or similar products.

---

## 🚀 Features

- **Watch Showcase Homepage** with visually appealing layouts
- **Product Details Page** for individual watch information
- **Fully Responsive Design** (desktop, tablet, mobile)
- **Tailwind CSS Styling** for clean and consistent UI
- **JavaScript Interactivity** for navigation and UI behavior
- **Well-Organized File Structure** for easy scalability
- **Node & npm Support** for Tailwind configuration

## 📥 Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone [https://github.com/Thoufeq/Watches.git](https://github.com/Thoufeq/Watches.git)
cd Watches

```

### 2️⃣ Run the Project (Simple Way)

You can directly open the project without any build step:

* Open `index.html` in your browser
* Or **right-click** -> **Open with browser**

### 3️⃣ Run Using a Local Server (Recommended)

```bash
npx serve .

```

Then open: `http://localhost:3000`

---

## ⚙️ Tailwind CSS Setup (Optional)

If you want to modify or rebuild Tailwind styles:

**1. Install dependencies**

```bash
npm install

```

**2. Build Tailwind CSS**

```bash
npm run build

```

> **Note:** You can customize styles in `tailwind.config.js`.
